# home-ued-archive

## 项目简介

`home-ued-archive` 是一个用于归档和发布多个独立 HTML 页面的仓库。  
本项目不针对任何特定网站或域名，仅作为静态 HTML 文件的长期存储与展示空间。

您可以将此仓库视为一个简单的页面归档集合，用于保存、分享或回顾曾经的页面设计、功能原型、活动页面等。

## 目录说明

```
home-ued-archive/
├── README.md          # 本文件
├── index.html         # 索引页面（可选）
└── pages/             # 归档页面存放目录
    ├── example-1/     # 示例归档子目录
    │   └── index.html
    └── example-2/
        └── index.html
```

- `pages/`：所有归档的 HTML 页面均放置在此目录下，每个项目建议使用独立子目录，便于管理。
- `index.html`：可选的根目录索引页，用于展示所有归档页面的链接列表（非必须）。

## 页面归档说明

归档的页面均为独立的 HTML 文件，通常包含完整的样式与脚本。  
每个归档页面的目录中，建议包含以下内容：

- 页面主文件（通常命名为 `index.html`）
- 相关资源文件（如 CSS、JS、图片等），如有需要可一同存放于同一子目录下

所有页面均为静态内容，不依赖后端服务或数据库。

## 维护说明

- 本仓库由维护者不定期更新，用于添加新的归档页面或修正现有内容。
- 如需贡献新的归档页面，请将完整页面文件放入 `pages/` 下新建的子目录中，并确保页面可独立运行。
- 请勿在页面中嵌入跟踪脚本、广告或外部资源请求（除非必要且可长期访问）。
- 所有提交应保持内容清晰、目录结构整洁。
